# v0.6.0-beta.2

以下变更以 v0.5 系列最后一个正式版本 **v0.5.7** 为基线，说明升级到 v0.6.0-beta.2 的完整变化。

## 新增截面与多因子引擎

- 在原时序策略引擎之外，新增因子图计算、时序与截面算子、多列因子输出、组合构建和 Full/Patch 目标组合。
- 支持通过 YAML 表达式编写因子，启动时编译为原生计算图；也可注册 Go 因子策略和自定义组合构建器。
- 新增因子研究、回测、归档和实盘入口；研究支持标签成熟、IC 诊断及等权、固定权重、历史 IC 组合。实盘暂不支持 history-ic。
- 因子回测提供 weights 近似权重账本和 events 事件执行两种模式；同一配置可同时运行时序与因子策略，混合历史回放使用 events 模式。

## 共享账户执行与实盘能力

- 新增共享执行账户、策略资本预算、净额执行和策略归属分配，支持保证金与风险约束、订单桥接、结算和幂等处理。
- 增加内存及 SQLite 执行存储、检查点恢复、启动对账、迁移与历史归档能力。
- 实盘启动验证数据、交易接口和账户能力；缺少必要证据时明确失败。预算来自对账后的真实账户，研究初始净值不向实盘账户充值。
- 配套依赖升级为正式版本 `banexg v0.2.65`，提供可选的执行验证、完整累计订单、结算现金和资金费记录接口；交易所差异继续由 banexg 封装。

## 数据与运行架构

- 引入任务级 Runtime 和统一 RunSpec，管理任务状态、时钟、账户、订阅、计算会话及 Stop/Join 生命周期。
- 统一历史与实时数据的订阅规划、初始化、分页预算和订阅代际，支持兼容消费者共享计算并保持账户及策略状态独立。
- 增加因子版本记录、不可变归档及决策快照，按当时可见数据计算，区分严格 PIT 与明确声明的最新值历史近似。
- 继续统一使用 `DataSeries.Values map[string]any` 传递 K 线及自定义数据，保留字段类型、NULL 和缺失键语义。
- 增加 QuestDB 元数据迁移、WAL 可见性等待、恢复标记及相关回归覆盖。

## v0.5 配置兼容性

- **v0.5 标准 YAML key 保持原名称和位置，无需版本标记。** 普通加载只读，不自动迁移、备份或改写配置文件。
- 未声明 `engine` 的旧策略保留时序运行及开放自定义参数；显式 `engine: time_series/factor` 启用新策略身份、账户和资本预算语义。
- 因子字段直接放在 `run_policy[]`；账户凭据、原交易参数和新执行覆盖放在根 `accounts`，公共执行默认值放在 `execution`。
- 新增 `data` 公共数据设置，并保留 `expressions`、`snapshot`、`portfolio`、`decision`、`research` 等相关配置分组。
- 补齐完整配置示例和 v0.5 对比说明，涵盖因子表达式、组合、归档、快照、manifest、混合预算、账户覆盖与历史覆盖。

升级说明见 [配置兼容性对比](config_compatibility.md)，完整示例见 [config.yml](config.yml)。

## 界面与文档

- 更新开发界面的配置和策略编辑、回测报告；配置保存支持摘要冲突检测与原子写入，减少覆盖外部修改的风险。
- 更新中英文指南、API 导航及架构文档，补充因子研究、混合回测、实盘接入和任意时序数据用法。
- 后端版本为 `v0.6.0-beta.2`；配套界面版本为 `v0.6.0-beta.1`，界面资源使用该版本已发布的 `dist.zip`。

## 验证与已知限制

- 使用 `GOWORK=off` 验证已发布的远程依赖，移除本地目录 `replace`；正式 Go 包测试、相关包静态检查、程序构建及模块校验通过。测试排除了被 Git 忽略的临时回放目录。
- 配置模板及因子、归档、混合示例解析通过，表达式编译通过；VitePress 构建及本地文档链接检查通过。
- Windows Go 1.25.1 构建使用 `-ldflags=-checklinkname=0`。界面生产资源已构建；现有前端类型检查仍有 17 个错误、2 个警告，尚未全部修复。
- 配套 banexg 的新增执行及 WebSocket 回归通过；其旧 `TestOdBookSide`、依赖 `local.json` 的实盘测试和缺少 `okx.md` 的文档生成测试未通过，默认 vet 仍有旧未命名结构体字段诊断，详见该依赖发布说明。
- 本版本为预发布；本地验证未覆盖真实交易所实盘验收及完整性能验收。严格 PIT、事件成交与实盘运行仍需实际数据、价格、资金费和账户能力证据。
