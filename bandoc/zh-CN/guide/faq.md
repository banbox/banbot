# 常见问题

## 如何升级 Banbot？

在策略项目中选择目标版本，更新依赖并重新编译：

```shell
go get github.com/banbox/banbot@VERSION
go mod tidy
go build -o bot
```

将 `VERSION` 替换为要使用的版本。只修改 `go.mod` 或执行 `go mod tidy` 不会更新已经部署的可执行文件。升级前保留配置、数据库和执行账本，并核对[配置](./configuration.md)与策略 API 的兼容性；当前源码要求 Go 1.26.0，声明 Go 1.26.8 工具链。

Docker 使用所选镜像版本更新容器，并保留数据卷；镜像的构建及启动参数以对应部署项目为准。

## 为什么需要策略项目？

Go 策略与 Banbot 一起编译成单个可执行文件。您可使用示例策略项目，也可[初始化自己的项目](./init_project.md)。修改 Go 策略后需要重新编译。因子引擎也支持在 YAML 中定义表达式和组合配置，见[多因子与截面](./factor.md)。

## 支持哪些策略与市场？

- 时序策略：按主/辅助周期或自定义序列事件计算，支持多品种、多周期、多账户。
- 因子策略：截面因子、组合研究、weights/events 回测、配对统计套利，以及时序/因子混合 events 回放。
- 实盘：普通时序路径与因子/混合路径的装配要求不同；因子/混合真实交易需要验证当前会话的数据、执行与对账能力，见[实时交易](./live_trading.md)。

当前内置交易所入口为币安、欧易、Bybit，行情和历史回测市场能力由 banexg 适配器提供；当前默认 Hub 实时执行仅接受 `prod`/`dry_run` 线性永续账户，见[共享账户与 Hub](./execution.md)。配对统计套利框架不等于已提供任意三角套利、跨所套利或高频交易策略；中国市场设计资料也不代表已交付股票/期货接入。

## 回测和下载数据是否需要 API 密钥？

公开行情回测和下载不需要交易密钥。实盘交易需要配置对应账户及环境的密钥。先按[快速开始](./quick_local.md)完成回测，再配置实盘账户。

## 为什么容器中的 WebUI 提示缺少密码？

`bot web` 在本机默认监听 `127.0.0.1:8000`，容器中默认监听 `0.0.0.0`。绑定 `0.0.0.0` 或 `::` 时必须传 `--password`，Basic Auth 用户名固定为 `banbot`。开发 WebUI 与实盘 Dashboard 的账号配置相互独立。

## 可以开空头仓位或限制订单数吗？

在支持做空的合约市场使用 `s.OpenOrder(&strat.EnterReq{Tag: "short", Short: true})`。现货路径不允许开空。

开单受余额、`max_open_orders`、账户限制及策略的 `EachMaxLong`/`EachMaxShort` 等约束，并非无限制。请求返回成功只表示已接受信号；订单是否成交由订单管理器与交易所决定。

## 可以只退出部分仓位吗？

在策略回调中使用：

```go
s.CloseOrders(&strat.ExitReq{Tag: "close", ExitRate: 0.5, FilledOnly: true})
```

可通过 `OrderID` 限定订单。详细字段和返回值见[策略 API](../api/strat.md)。

## 修改配置后需要重新启动吗？

YAML 不是自动热更新接口，编辑后通常需重启。运行时的品种增删和远程控制走各自接口。重启时的订单同步、共享账户恢复和接管要求不同，应保留原配置、订单库、执行账本及检查点；不能仅凭交易所当前持仓推断全部策略归属。见[实时交易](./live_trading.md)。

## 回测、实时模拟和历史回放有什么不同？

普通时序策略的 `env: dry_run` 消费实时行情并在本地模拟成交。因子/混合配置的 `trade --dry-run` 是历史 events 回放。`backtest --mode weights` 用于因子权重研究；混合回放必须使用 events。详见[回测](./backtest.md)。

## 实盘与回测订单为什么不一致？

先检查日志、实际加载的配置、品种池、时区、周期、杠杆和金额，再比较行情、手续费、滑点、资金费与成交条件。OHLCV 撮合无法完整还原盘口、网络延迟和真实成交顺序。第三方数据还需核对历史可见时间及修订版本。

## 数据下载或写入后为什么暂时查不到？

先检查数据库连通性、日志和 `database.max_pool_size`。QuestDB WAL 表写后异步可见，写入成功不代表立即可读；不要因一次空结果清库或覆盖旧表。修复 K 线覆盖范围可使用[数据工具](../advanced/kline_tools.md)的 `kline repair-ranges`，先核对实际存储区间。

## SQLite 提示 float64 字段违反 NOT NULL 约束？

NaN/Inf 写入 SQLite 可能转换成 NULL。对必须为有限数值的订单/报告字段，在写入前校验或使用 `utils.NanInfTo(v, 0)`。自定义时序数据中显式 NULL 与缺失字段有独立语义，不应一律替换为 0。

## 下载 Go 依赖出现 unexpected EOF？

检查 `GOPROXY`、网络和代理节点；切换到可访问的源或节点后重试。区分依赖下载错误与运行时交易所连接错误。

## 还有问题时提供什么信息？

请结合[命令行](./bot_usage.md)和[API](../api/index.md)核查，并在项目 issue 或社区交流时附上版本、命令、脱敏配置、错误日志与最小复现。配置和日志中不要公开 API 密钥、密码或 token。
